# 交付验收纪律（先质检，后签收）

## 何时适用

本项目**任何一次"文件类交付"**都适用：工人往项目目录里写出了 pptx / docx / xlsx / 报告 / 数据文件。
不适用：纯问答、纯检索、只读浏览目录这类不产出文件的活。

## 一、硬流程（顺序不许调）

1. 工人交回文件 → **先别看文件，也别对用户说"已完成"**。
2. 立刻派一张**质检单**给测试岗（见第二节怎么写）。
3. 读质检报告的最后一行「结论：」：
   - `结论：通过` → 才可以对用户签收，并把质检报告里的实测数字带上（页数、字节数、SHA-256）。
   - `结论：打回（…）` → 派**返工单**给原来那个工人，逐条带上缺陷。返工完再回第 2 步重新质检。
4. **最多两轮返工**。第三轮仍不过，如实告诉用户当前挂着哪几条、文件在哪，不要继续空转，也不要降级成"通过"。

收到形如「XX 交回一份质检裁决：结论「打回」」的系统通知，就是第 3 步到了——**这一轮必须动手**，
不要只回一句"收到"就停下，也不要等用户来问。

## 二、质检单怎么写（照这个填，别自由发挥）

```
对 <被检文件绝对路径> 做交付质检，按「中文演示文稿质检规格」逐项判定。
本次交付依据的规格原文要点：<把当初派给工人的硬指标抄过来，至少含页数、每页条数、每条字数、页码页脚、中文字体、禁用占位词>
要求：只裁不改，不许碰被检文件；报告最后一行必须原样出现「结论：通过」或「结论：打回（…）」；
必须附实际执行的命令、15 行 [PASS]/[FAIL] 输出、文件字节数与 SHA-256。
```

要点必须**抄规格原文**而不是复述大意——复述会把"每条 8~28 字"说成"字数适中"，
测试岗就没法判了。

**规格名按文件类型选，一个字都别改**（测试岗的菜谱是靠这几个字路由的，写错了它手里没尺子）：

- `.pptx` → 「中文演示文稿质检规格」，脚本 `check_ppt.py`
- `.docx` → 「中文文档质检规格」，脚本 `check_docx.py`
- `.xlsx` → 「电子表格质检规格」，脚本 `check_xlsx.py`

派单时把规格名原样写进质检单第一句，例如
`对 /绝对路径/产品说明.docx 做交付质检，按「中文文档质检规格」逐项判定。`

## 二·五、派工单也要点规格名（写作侧）

上面三条是**质检**用的尺子。工人那侧还有**交付规格**，派工单第一句必须原样写上它，
否则工人的菜谱路由不到，交回来的东西只能靠质检打回再返工，白花一轮：

- 要 `.pptx` → 「中文演示文稿交付规格」
- 要 `.docx` → 「中文 Word 文档交付规格」
- 要 `.xlsx` → 「电子表格交付规格」

写法（一张单子上两个名字都要有：交付规格给工人，硬指标抄给工人）：

```
按「中文 Word 文档交付规格」产出 <文件名.docx>，放到 <项目绝对目录>。
必须满足的硬指标（抄规格原文，不许概括成"排版规范"）：
一级标题唯一且 ≤20 字、小标题 ≥2 个、标题不跳级、正文中文 ≥300 字、
每段 15~200 字、真编号列表非手打圆点、eastAsia 东亚字体、正文 ≥10.5pt、
页脚署名 + PAGE 页码域、无占位词。
交付前自己跑一遍 check_docx.py，把 15 行输出附在报告里。
```

Excel 的硬指标换成：表名有意义、表头非空不重名且加粗、表头行不合并、数据行 ≥5、
数字存成数字、百分比存小数带 `0%` 格式、逐列列宽、`freeze_panes="A2"`、无整列空/整行空。
PPT 的硬指标换成：页数 6–10、每页 1 标题 + 3–5 条要点、每条 8–28 字、16:9、无空占位符、页码页脚。

## 三、返工单怎么写

```
打回复工。质检结论：<原样抄「结论：打回（3 条不合格：…）」>
逐条缺陷：
1. <标准名> | 实测 <值> | 第 <N> 页
2. ...
要求：改生成脚本后重新产出同名文件，不要手改 .pptx；
除 <文件名> 与其生成/自检脚本外，不得改动项目里任何其它文件；
完成后必须自己重跑质检脚本，把 15 行输出附在报告里。
```

## 四、严禁

- **未质检就报"已完成"**：这是本项目最严重的一次事故级别，比晚交付更糟。
- **自己替工人做检查**：你没有跑脚本的手，你有派单的手。看一眼就说"没问题"不算质检。
- **把打回偷偷降级**：质检写打回，你对用户说"基本可用，小瑕疵" —— 不许。
- **让工人自己给自己验收**：质检单必须派给测试岗，不能回给原作者。
- 项目里**暂时没有测试岗**时：如实说明"本项目没有质检岗，这一单没走验收"，
  并提议用户「添加员工」补一个，别装作走完了流程。

## 五、用户明确豁免

用户当轮说了"不用质检 / 直接给我 / 快点"这类话，可以不派质检单，
但签收时必须带一句：**"本次未过质检，按你的要求直接交付。"**
